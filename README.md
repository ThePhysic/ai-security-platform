# AI Security Platform

AI-powered security engineering platform for application
security, secure developer workflows, and agentic triage.

Status: Phase 0 planning not yet started.

## Goals
- Application and dependency security analysis
- Infrastructure and CI/CD security guardrails
- Evidence-based, bounded AI vulnerability triage
- Developer-facing remediation and reporting
- Reproducible security and adversarial evaluations

See docs/PROJECT_BRIEF.md for approved initial scope.

Implementation architecture and dependencies will be
decided during Phase 0.
